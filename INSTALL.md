# 📦 Installation Guide for IKPS v1.0.0

## Quick Install

```bash
git clone https://github.com/gitdeeper12/IKPS.git
cd IKPS
npm install
```

Run Development Server

```bash
npm run dev
```

Build for Production

```bash
npm run build
```

Run Tests

```bash
npm test
```

---

Requirements

Package Version
Node.js ≥ 18.0.0
npm ≥ 9.0.0
React ≥ 18.0.0
TypeScript ≥ 5.0.0

---

Platform Support

Platform Support
Linux ✅ Fully tested
macOS ✅ Compatible
Windows ✅ Compatible
Termux (Android) ✅ Compatible

---

Docker Installation

```bash
docker build -t ikps:latest .
docker run -it --rm ikps:latest
```

---

Uninstall

```bash
rm -rf IKPS
```
